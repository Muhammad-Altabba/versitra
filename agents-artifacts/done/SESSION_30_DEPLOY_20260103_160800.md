## Troubleshooting Guide

### Issue: Authentication Failed

**HTTPS Solution**:
```bash
# Use Personal Access Token as password
git push origin main
# Username: your_github_username
# Password: ghp_xxxxxxxxxxxxxxxxxxxx (your PAT)
```

**SSH Solution**:
```bash
# Set up SSH key
ssh-keygen -t ed25519 -C "your_email@example.com"
cat ~/.ssh/id_ed25519.pub  # Copy this
# Add to https://github.com/settings/keys
git remote set-url origin git@github.com:YOUR_USERNAME/git-translation-platform.git
git push origin main
```

### Issue: Tests Failing in CI

**Check**:
1. View Actions tab logs
2. Download test artifacts
3. Look for error messages

**Common Causes**:
- MySQL connection issues (check service health)
- Playwright browser installation (check install step)
- Environment variables missing (check workflow env)

### Issue: Build Failing

**Check**:
1. TypeScript errors: `pnpm check`
2. Dependencies: `pnpm install`
3. Build locally: `pnpm build`

**Common Causes**:
- Type errors in code
- Missing dependencies
- Build configuration issues
